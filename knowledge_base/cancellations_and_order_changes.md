# Cancellations and Order Changes

## Cancelling an order
You can cancel an order at no cost while its status is Processing. Open Your Orders, choose the order and select Cancel items. The refund for a cancelled order goes back to the original payment method within 3 to 5 business days.

## After an order has shipped
Once the status changes to Shipped the order can no longer be cancelled. You can refuse the delivery or return the items after they arrive, following the Returns and Refunds Policy.

## Changing items or quantities
Items and quantities cannot be edited after an order is placed. To change them, cancel the order while it is Processing and place a new order.
